三、本地保存的数据
启动器在当前 Windows 用户的 %LOCALAPPDATA%\PIgHeAD\Launcher 中保存启动设置、协议版本及内容校验值、同意时间、加密认证缓存和游戏日志；在您选择的游戏目录保存游戏文件、依赖和实例数据。协议记录只用于判断是否需要再次征求同意，不会作为已取得第三方授权的证明。

四、凭据安全
Microsoft 令牌缓存使用 Windows DPAPI 当前用户范围加密；Xbox 和 Minecraft 令牌只在内存中使用，不写入设置 JSON。启动器不记录完整启动命令，并遮盖游戏日志中的当前 Minecraft 令牌。相同 Windows 用户下可检查进程参数的软件仍可能读取传给 Java 的令牌，请保护设备和系统账户。

五、遥测、日志与删除
当前版本没有启动器遥测或自动上传日志功能；您安装的游戏、加载器、模组和外部安装器可能另有数据行为，应查看其说明。游戏日志可能包含玩家名、本机路径、服务器地址等信息，请检查和脱敏后再分享。可在 Accounts 退出并清除本启动器认证缓存；删除本地数据前请关闭启动器并备份需要保留的内容。删除协议记录后，下次启动需要重新同意。
