# PIgHeAD · beta v0.2.2 更新说明

**简体中文** | [English](Update-Notes-v0.2.2.en.md)

发布日期：2026-10-22 · Git 标签：`v0.2.2-beta` · Windows x64 预发布

[发布与下载](https://github.com/P1gHeADOFOG/PIgHeAD-Launcher/releases/tag/v0.2.2-beta) · [README](../README.md)

## 界面与主题

- 主窗口、按钮、输入框和卡片统一圆角，Windows 11 使用系统圆角与阴影。
- 新增浅色模式；浅色主页采用蓝天、阳光、白云和绿色山地，深色模式保留暮色风景。
- 复选框统一主题色与圆角，覆盖勾选、半选、禁用和键盘焦点状态。
- 新增中英文即时切换，标题栏及 Settings 均有入口；页面、状态、文件选择标签及协议提供英文。
- 主题和界面语言自动保存在启动器旁的 `PHL/appearance.json`，切换游戏目录时仍保持。界面语言与 Minecraft 游戏语言分别设置。
- 新增猪头图标缩放、淡入、像素点与淡出的开屏动画，遵循启动器和 Windows 的动画设置。
- Home 改为随窗口高度伸缩，启动按钮、下载选项与底部状态无需滚动；最小窗口为 1000 × 640 WPF 逻辑像素。

## 下载中心

- 启动时自动读取正式版本，进入 Downloads 无需手动刷新。
- 最近 6 个正式版本可点击版本号直接下载安装，更多版本在下拉框选择。
- 切换 Forge、NeoForge、Fabric、Quilt 或 Minecraft 版本时自动匹配兼容构建；丢弃过期请求的结果，失败后可重试。
- 目录读取使用独立加载状态，不占用文件安装任务锁；慢速或失败的目录请求不会阻止已有本地游戏启动。
- 原版与加载器继续使用官方来源。OptiFine 仍使用官网与外部官方安装器流程，不自动组合加载器。

## 本地版本管理

- Versions 仅管理本地版本，移除在线列表和直接安装按钮，新增“前往下载中心”。
- 每个版本新增“详情”和“删除”。详情显示 Minecraft 版本、加载器及版本号、Java 要求、版本类型、发布时间、版本目录大小和实际目录。
- 识别到 Forge / NeoForge / Fabric / Quilt 时显示“查看模组”；原版或未识别到加载器时隐藏入口，不根据版本名称猜测。
- 模组列表读取实际运行目录 `mods` 中启用的 JAR，支持 Fabric、Quilt、Forge、NeoForge 及旧版 `mcmod.info` 资料，展示名称、ID、版本、文件名和读取状态。
- 模组查看遵循共享目录、版本隔离和导入实例布局。仅读取资料，不执行 JAR、不依赖外部 API Key，也不代替模组兼容性验证。
- 删除前弹层展示具体目录及范围，确认后移入 Windows 回收站；所选目录内的存档、模组和配置随目录移动。共享 libraries / assets、根目录数据和独立 instances 目录保留。
- 仍被其他版本继承的基础版本禁止删除；路径越界、循环继承和链接会被拒绝。删除或其他文件操作期间阻止冲突任务。

## 便携目录与分发

- 完整版和精简版均提供单文件 EXE；完整版自带 .NET，精简版需要 .NET 10 Desktop Runtime x64。
- 将 EXE 放在整合包旁，可识别附近 `.minecraft` 和匹配的本地 Java；游戏设置、日志与启动器目录列表按 PHL 布局保存。
- 支持已登记游戏目录切换，整合包内路径与 Java 提示以相对位置恢复；认证缓存仍使用当前 Windows 用户 DPAPI。
- 首次使用协议提供中英文，内容校验覆盖两种语言；文档变化后重新确认。旧用户目录及旧认证缓存不会自动删除或复制。
- README、更新说明及第三方许可证随发布打包。界面版本统一为 `beta v0.2.2`，程序集 / 文件版本为 `0.2.2.0`，程序信息版本为 `0.2.2-beta`。

## 验证与已知限制

- Release 构建通过，零警告、零错误；120 项自动测试通过。
- 覆盖主题和双语绑定、1000 × 640 / 1135 × 720 / 1280 × 820 主页布局、自动目录、取消与过期响应、本地详情、模组格式及损坏资料、删除确认与范围、继承依赖、便携目录和 DPAPI。
- 删除测试仅操作临时目录并模拟回收过程，不删除用户游戏。完整游戏下载、实际 Windows 回收站操作、真实游戏窗口和正版服务器认证仍需目标环境验收。
- 根据当前项目记录，Minecraft Services API 尚未获批；Microsoft OAuth 注册不等于获得 Minecraft API 权限，真实正版登录仍待验收。
- 本项目仍为 beta；模组资料可读不代表兼容或安全，未识别资料会保留文件名与状态。项目使用限制见 README。
